# 星星快手 🌟

一个轻松有趣的 20 秒反应力小游戏。点击随机出现的星星，看看你能拿到多少分！

## 在线体验

启用 GitHub Pages 后即可通过网页链接游玩。

## 怎么玩

1. 点击「开始挑战」。
2. 在 20 秒内，尽可能多地点击游戏区域里出现的星星。
3. 每点中一次得 1 分。
4. 时间结束后查看成绩，点击「再玩一次」继续挑战。

## 功能

- 20 秒限时挑战
- 星星随机出现位置
- 实时得分与倒计时
- 使用浏览器本地存储记录个人最佳成绩
- 适配电脑和手机屏幕
- 纯 HTML、CSS、JavaScript，无需安装依赖

## 本地运行

下载或克隆仓库后，直接用浏览器打开 `index.html` 即可。

## 使用 GitHub Pages 发布

1. 打开仓库的 **Settings → Pages**。
2. 在 **Build and deployment** 中选择 **Deploy from a branch**。
3. Branch 选择 `main`，目录选择 `/(root)`，然后点击 **Save**。
4. 等待 GitHub Pages 发布完成后，页面会显示访问网址。
